# Blog keyword map

One keyword, one post. Add a row here before writing a post; `pnpm blog:check` reads this
table and fails when a keyword has two owners, when a row that is not `planned` has no post,
or when a post's primary keyword, slug or title disagrees with its row. How the blog works is
in [Blog](./BLOG.md).

Intent is one of `learn`, `compare`, `do`, `buy`. Status is `planned` (no post yet) or
`published`.
