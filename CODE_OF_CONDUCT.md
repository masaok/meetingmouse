# Code of conduct

Meet Mouse is a small project and this is a short document.

- Be kind and assume good faith. Disagree with ideas, not people.
- Review the work, not the author. Say what is wrong and, where you can, how you would fix it.
- Newcomers are welcome. A question that is obvious to you is not obvious to everyone.
- No harassment, discrimination, personal attacks or unwelcome sexual attention, in issues, pull requests, commits or anywhere else connected to the project.

If someone is making the project unpleasant for you, contact the maintainer privately through
the address on their GitHub profile. Reports are read by a person and handled discreetly.
Maintainers may edit, remove or lock contributions that break these rules and may block
repeat offenders.
